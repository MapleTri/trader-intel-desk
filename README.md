# 📊 每日交易员情报台

免费的私人股市情报站：每天 08:00 由 AI 自动化精选加工 A股/韩股/美股情报，每条带方向判断（🔴利好 / 🟢利空 / ⚪中性）与受益板块，支持按市场（中国/韩国/美国）与方向双维筛选。

## 页面功能

- ⚡ 30秒速览 · 📈 中韩美 11 项指数卡（涨红跌绿）
- 🧭 板块动态 · 📊 板块涨跌榜 TOP10 · 🌡 情绪温度计（涨停/跌停/炸板率/连板梯队）
- 📆 宏观数据日历 · 解禁日历 · 业绩预告雷区
- 🆕 昨日新增 · 📅 本周周报（政策/行业/公司/海外 4 类累积）· 🗂 上周回顾
- 📝 交易计划与复盘（数据仅存本机浏览器）

## 数据更新

- 每日 08:00 自动采集加工，工作日 08:30 自动发布本仓库
- 纯静态站点，本地双击 `index.html` 亦可离线使用
