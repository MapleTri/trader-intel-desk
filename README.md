# 📊 每日交易员情报台（网页版）

免费的私人股市情报站：每天 08:00 由 AI 自动化精选加工 A股/韩股/美股情报，每条带方向判断与受益板块，支持市场/方向双维筛选。纯静态、零依赖、本地双击即用。

## 快速开始

双击 `index.html` 即可使用。数据由每日 08:00 自动化任务更新（无需人工干预）；公网固定地址 **https://MapleTri.github.io/trader-intel-desk/**（GitHub Pages，工作日 08:30 自动发布，地址永不变）。
